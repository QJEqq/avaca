# Security

**Русский.** Уязвимость лучше не описывать в открытом issue. Сообщите через
[приватный отчёт GitHub](https://github.com/QJEqq/avaca/security/advisories/new): что затронуто,
как воспроизвести, на какой версии. Ответ — в течение недели; исправление выйдет отдельным релизом,
а в его заметках будет ссылка на отчёт.

Поддерживается последняя версия из [релизов](https://github.com/QJEqq/avaca/releases/latest).

Не прикладывайте к отчётам рабочие ссылки подписок, ключи REALITY и адреса своих серверов — они не
нужны для разбора и останутся в истории.

**English.** Please do not describe a vulnerability in a public issue. Report it through
[GitHub private reporting](https://github.com/QJEqq/avaca/security/advisories/new): what is affected,
how to reproduce it, which version. Expect an answer within a week; the fix ships as its own release,
with the report linked from its notes.

Only the latest [release](https://github.com/QJEqq/avaca/releases/latest) is supported.

Keep live subscription links, REALITY keys and your server addresses out of reports — they are not
needed to investigate and would stay in the history.
